# 彼岸花 — Three.js 3Dモデル

Three.js（r160）で手続き的に生成した、彼岸花（*Lycoris radiata*）一本の3Dモデルです。背景・地面などはなく、モデル単体を表示します。

`index.html` をブラウザで開くだけで動作します（Three.js は CDN から読み込み）。
ローカルサーバー経由で開く場合: `python3 -m http.server` → http://localhost:8000

## モデルの構成
- **花被片**: 強く反り返り、縁が細かく波打つ6枚の花被片。葉脈テクスチャとバンプ、シーン（ベルベット感）、薄い花弁の透過光をシェーダーで近似
- **雄しべ・雌しべ**: 花被片の約2倍の長さで上方に弧を描く先細りチューブ、丁字着の葯
- **花序**: 5〜7輪の散形花序、乾いた総苞片、葉のない花茎（高さ約42cm、1単位 = 1cm）

## 操作
- ドラッグ: 回転 / ホイール: ズーム / `R`: 自動回転の切替
- 右上の「GLB で保存」でモデルを `higanbana.glb` として書き出し（Blender などで読み込み可。透過光の表現はブラウザ表示のみ）
