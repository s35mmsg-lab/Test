# 彼岸花 — Three.js

Three.js（r160）で手続き的に生成したフォトリアルな彼岸花（*Lycoris radiata*）のシーンです。

`index.html` をブラウザで開くだけで動作します（Three.js は CDN から読み込み）。
ローカルサーバー経由で開く場合: `python3 -m http.server` → http://localhost:8000

## 主な表現
- **花被片**: 強く反り返り、縁が細かく波打つ6枚の花被片をメッシュで生成。葉脈テクスチャとバンプ、シーン（ベルベット感）、薄い花弁の透過光をシェーダーで近似
- **雄しべ・雌しべ**: 花被片の約2倍の長さで上方に弧を描く先細りチューブ、丁字着の葯
- **花序**: 5〜7輪の散形花序、乾いた総苞片、葉のない花茎
- **環境**: 夕暮れの物理空（Sky）による IBL、長い影、風に揺れる草（インスタンシング）と花、遠景の山並みと大気の霞
- **ポストプロセス**: 被写界深度（Bokeh）、控えめなブルーム、ACES トーンマッピング、MSAA

## 操作
- ドラッグ: 回転 / ホイール: ズーム
- `D`: 被写界深度の切替 / `R`: 自動回転の切替
