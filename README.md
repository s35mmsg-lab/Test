# 彼岸花 — Three.js 3Dモデル

Three.js（r160）で手続き的に生成した、彼岸花（*Lycoris radiata*）一本の3Dモデルです。スタジオ表示ではモデル単体を、シネマ表示では夜の群生の中の一本として表示します。

`index.html` をブラウザで開くだけで動作します（Three.js は CDN から読み込み）。
ローカルサーバー経由で開く場合: `python3 -m http.server` → http://localhost:8000

## モデルの構成
- **花被片**: 強く反り返り、縁が細かく波打つ6枚の花被片。葉脈テクスチャとバンプ、シーン（ベルベット感）、薄い花弁の透過光をシェーダーで近似
- **雄しべ・雌しべ**: 花被片の約2倍の長さで上方に弧を描く先細りチューブ、丁字着の葯
- **花序**: 1本に6〜10輪（各花の花被片は6枚）の散形花序。主役の株は8輪、乾いた総苞片、葉のない花茎（高さ約42cm、1単位 = 1cm）

## 表示スタイル
- どの表示でも、茎が根元からしなやかにしなり、花被片と雄しべが小さく震えるように静かに揺れる（頂点シェーダー。影・被写界深度・線画にも同じ揺れを適用）
- **シネマ**（初期表示）: 夜の濃紺の空を背景に、背後上方の月光で花弁が赤く透け、奥の群生と浮遊する塵が被写界深度でボケる映画風の写実表示。ブルーム、寒色寄りの色調、ビネット、フィルム粒子付き
- **スタジオ**: 背景なしのスタジオ照明下で、モデル単体を PBR 表示。花弁・雄しべ・子房/花柄・茎・葯・苞にそれぞれ手続き的テクスチャ（色・凹凸・光沢ムラ）
  - 花被片は4種類のテクスチャ（標準・深紅・花粉の付いた緋色・先端が褐変したもの）から1枚ずつ選び、縁ほど強く透ける
  - 茎には傷と根元の土汚れ、苞には乾いて裂けた膜状の縁
- **イラスト**: トゥーン陰影に、深度と法線から抽出した墨色の線画、暗部の斜線、顔料のざらつき、和紙の地を重ねた日本画風の表示（細い雄しべは線を弱める）
  - タッチのプリセット: 日本画 / アニメ / 水彩 / 鉛筆 / 墨と朱 / アメコミ
  - 「細かく調整」で 線の太さ・濃さ・揺らぎ、陰影の段数・影の濃さ、彩度、紙の質感、にじみ、斜線、網点、モノクロ を個別に変更可能

## 操作
- ドラッグ: 回転 / ホイール: ズーム / `R`: 自動回転の切替 / `1` `2` `3` または右上のボタン: シネマ・スタジオ・イラスト
- 右上の「GLB で保存」でモデルを `higanbana.glb` として書き出し（Blender などで読み込み可。透過光の表現はブラウザ表示のみ）
